# TANITY Global Med Comms

Static website for TANITY Global Med Comms, hosted through GitHub Pages at
[www.tanityglobal.com](https://www.tanityglobal.com).

## Local preview

From the repository root, run a simple static server and open the printed local
address in a browser. For example:

```sh
python3 -m http.server 8000
```

The consultation and contact forms submit to Formspree. Do not submit real form
data during local visual testing. The website privacy notice documents this
processor relationship and should receive legal review before production merge.
